# Contributing

Add demos under **Latest Opus 5.5 video prompts** by editing `data/entries.json` (then run `python3 scripts/extract_prompts.py && python3 scripts/build_readme.py`), or send a PR with:

1. Title + author @handle + original post URL (X, GitHub, or an official Anthropic page)
2. Evidence the video was made **with Claude Opus 5.5** (the creator says so in the post or thread)
3. The prompt **exactly as the creator published it** in a `text` fence — or mark it “not shared”. Never paraphrase or reconstruct a prompt.
4. Optional preview under `assets/previews/` and a compressed clip under `assets/videos/<slug>-readme.mp4` (≤10 MB; full video stays on X)
5. EasyVeo CTA only as the standard “Remake with EasyVeo” link

Do not upload copyrighted audio beyond the short compressed preview of the creator’s own post. Creators can ask for removal at any time (open an issue).
